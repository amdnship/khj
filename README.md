
# 탐구 보고서 요약 
1. 탐구 제목 

그래프 신경망 기반 이온화 지질 구조를 활용한 mRNA 전달 성능 예측·분석 

 

2. 탐구 동기 

지질나노입자(LNP) 기반 핵산 전달 기술에 대한 관심을 확장하여 ‘그래프 신경망 기반 이온화 지질의 구조를 활용한 mRNA 전달 성능 예측·분석’을 수행하였다. 

 

3. 탐구 내용 

-  이온화 지질 1,100종의 분자 구조를 그래프로 변환하고 메시지 전달 기반 GNN을 직접 구현하였다. 

-  구조 유사성 기반 군집 분할에서 예측 성능 저하 문제를 확인하고, 그래프 집계 방식 조정과 분자량 등 물리화학적 특성 결합으로 모델의 예측 성능을 향상시켰다. 

-  분자 지문 기반 랜덤 포레스트와 예측 성능을 비교하고, 데이터 분할 조건에 따른 성능 차이와 일반화의 한계를 분석하였다.
