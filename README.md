『부분과 전체』를 읽고 ‘과학적 지식은 대화와 비판 속에서 어떻게 형성되고 발전하는가?’라는 탐구 질문을 제기하였다. 이를 바탕으로 대화를 통한 관점 비교, 비판을 통한 한계 검토, 학문 간 융합을 통한 새로운 질문과 해석의 확장이 과학 발전에 기여한다는 관점을 형성하고, 나아가 『추측과 논박』과 『생명이란 무엇인가』를 추가로 찾아 읽어 각 저자의 논의를 근거로 관점을 구체화하였다.  
이를 확장하여, 책대화에서 ‘모든 비판이 과학 발전에 도움이 되는가?’, ‘학문 간 융합이 잘못된 해석으로 이어질 수도 있는가?’라는 확장 질문을 바탕으로 기존 관점을 비판적으로 재검토하여, 비판과 학문 간 융합의 한계와 과학 발전에 기여하기 위한 조건을 심화 탐구하였다.  
포퍼가 아인슈타인의 중력이론을 사례로 설명한 관측을 통한 이론의 반증 가능성을 추가로 검토하여, 과학 발전에 기여하는 비판에는 실험적·논리적 근거에 따른 구체적인 문제 제기가 필요하다고 판단하였다. 또한 슈뢰딩거가 인정한 다른 분야에 대한 불완전한 이해의 위험을 검토하여, 학문 간 융합에는 각 분야의 개념에 대한 정확한 이해와 신중한 해석이 필요하다는 조건을 도출하며 관점을 정교화하였다.
