## 1. 탐구주제

그래프 신경망 기반 이온화 지질 구조를 활용한 mRNA 전달 성능 예측·분석

## 2. 탐구 동기

지질나노입자(LNP) 기반 핵산 전달 기술에 대한 관심을 확장하여 ‘그래프 신경망 기반 이온화 지질 구조를 활용한 mRNA 전달 성능 예측·분석’을 수행하였다.

## 3. 이론적 배경

지질나노입자(LNP)는 핵산을 보호하고 세포 내 전달을 돕는다. 주요 구성 성분인 이온화 지질은 pH에 따라 전하 상태가 달라져 입자 형성과 엔도솜 막과의 상호작용에 영향을 줄 수 있다. 다만 최종 전달 성능은 지질 구조 외에 제형·세포 조건 등 여러 요인의 영향을 받는다.  

그래프 신경망(GNN)은 원자를 노드, 화학 결합을 간선으로 표현하고, 주변 원자의 정보를 반복 전달하는 메시지 전달(Message Passing)을 통해 분자 특징을 학습한다. 원자별 특징을 통합하는 Readout 이후 세포 실험의 mRNA 형질도입 지표(Target)를 예측한다. 이 수치는 체내 전달 효율(%)이나 치료 효과를 직접 의미하지 않는다.


## 4. 탐구 방법

**① 자료·전처리** LANTERN의 정제된 AGILE 데이터(이온화 지질 1,100종)를 사용하였다. RDKit으로 SMILES를 분자 그래프로 변환하고 원자 특징 11개, 결합 특징 4개를 추출하였다. 별도로 분자량·LogP·극성 표면적 등 분자 기술자 8개를 계산하였다.  

**② 모델 구현·개선** PyTorch로 3층 메시지 전달 GNN을 구현하였다. 구조 군집 분할에서 예측 성능 저하를 확인한 뒤, 그래프 집계 방식을 조정한 GNN과 분자량 등 물리화학적 특성을 결합한 GNN으로 개선하였다. 분자 기술자 기반 MLP와 Morgan 지문 기반 랜덤 포레스트(RF)를 비교 모델로 두었다.  

**③ 학습·평가** 무작위 분할(seed 42·123)은 학습/검증/시험 770/165/165개, 분자 지문 기반 K-means 구조 군집 분할은 807/145/148개로 구성하였다. AdamW·MSE 손실로 최대 80회 학습하고 검증 손실로 모델을 선택하였다. 시험 집합에서 R²·MAE·RMSE를 계산했다. 군집 분할은 엄밀한 스캐폴드 분할은 아니다.  

## 5. 탐구 결과 및 분석

동일한 세 가지 분할 조건에서 다섯 모델의 결정계수(R²)를 비교하였다. R²는 높을수록 좋으며, 음수는 해당 시험 집합에서 평균값 기준보다 제곱오차가 크다는 뜻이다.  

| 모델 | 무작위 42 | 무작위 123 | 구조 군집 42 |
| --- | --- | --- | --- |
| 기존 GNN | 0.2825 | 0.1607 | -0.0742 |
| 집계 조정 GNN | 0.367 | 0.3542 | -0.2576 |
| 특성 결합 GNN | 0.427 | 0.38 | 0.1495 |
| 분자 기술자 MLP | 0.2655 | 0.2517 | 0.209 |
| Morgan 지문 + RF | 0.5081 | 0.4805 | 0.339 |


**① 모델 개선 효과** 기존 GNN의 R²는 무작위 42에서 0.2825, 무작위 123에서 0.1607이었다. 그래프 집계 방식 조정과 분자량 등 물리화학적 특성을 결합한 개선 모델은 각각 0.4270, 0.3800으로 향상되었다. 구조 군집 분할에서도 -0.0742→0.1495로 개선됐지만, 예측력은 제한적이었다.  

**② 일반화 성능의 한계** 구조 군집 분할에서 집계 조정 GNN은 R²=-0.2576으로 악화됐다. 같은 분할에서 분자 기술자 MLP(0.2090)와 Morgan 지문 RF(0.3390)는 특성 결합 GNN(0.1495)보다 우수했다. 즉, 복잡한 그래프 표현이 새로운 분자 구조에 대한 예측력을 항상 높이지는 않았다.  

## 6. 결론 및 고찰

이온화 지질 1,100종의 분자 구조를 그래프로 변환하고 메시지 전달 기반 GNN을 구현하였다. 구조 군집 분할에서 예측 성능 저하 문제를 확인한 후, 그래프 집계 방식을 조정하고 분자량 등 물리화학적 특성을 결합하여 예측 성능을 향상시켰다. 또한 분자 기술자 기반 MLP 및 Morgan 지문 기반 랜덤 포레스트를 GNN과 비교하고, 분자 구조 표현 방식과 데이터 분할에 따른 일반화의 한계를 분석하였다.  

본 결과는 공개된 세포 실험의 형질도입 지표에 관한 탐색적 평가이며 LNP의 실제 치료 효과를 증명하지 않는다. 기존 시험 결과를 참고해 모델을 개선했으므로 향후 사전에 분리한 독립 데이터에서 추가 검증이 필요하다.
